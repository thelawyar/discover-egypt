## Discover Your Town (durtown.com)

دليل تجاري شامل للمدن المصرية، واجهة عربية RTL نظيفة على غرار جوجل، مع لوحة تحكم للأدمن وتسجيل أصحاب الأنشطة.

### المرحلة الأولى (نطاق هذه الخطة)
الدليل + لوحة التحكم. الإعلانات والفعاليات لاحقًا (الجداول تُصمَّم بحيث تستوعبها بدون إعادة هيكلة).

### الصفحات
```text
/                    صفحة البحث (شعار + شريط بحث في المنتصف + فلتر مدينة + تصنيفات سريعة)
/search?q=&city=     نتائج البحث ككروت + فلاتر جانبية (المحافظة، المدينة، التصنيف)
/business/$id        صفحة تفاصيل النشاط (معرض صور، بيانات اتصال، خريطة، تقييمات)
/city/$slug          صفحة المدينة: أشهر التصنيفات وأحدث الأنشطة
/auth                تسجيل دخول / إنشاء حساب
/dashboard           لوحة صاحب النشاط: إضافة/تعديل أنشطته ومتابعة حالة المراجعة
/admin               لوحة الأدمن: مراجعة الأنشطة، إدارة المحافظات والمدن والتصنيفات
```

### تجربة البحث
- بحث حر واحد يغطي: اسم النشاط، التصنيف، الوصف، المنتجات/الخدمات، العنوان.
- فلتر مدينة اختياري بجوار الحقل، مع فلاتر جانبية في صفحة النتائج.
- حالة البحث كلها في الـ URL (قابلة للمشاركة والفهرسة).
- بحث نصي كامل في قاعدة البيانات مع دعم العربية والترتيب حسب الصلة ثم الأنشطة المميزة.

### بيانات النشاط
أساسية: الاسم، التصنيف، الوصف، المحافظة، المدينة، العنوان، تليفون، واتساب، صور، مواعيد العمل.
إضافات: قائمة المنتجات/الخدمات (وسوم قابلة للبحث)، روابط السوشيال والموقع، إحداثيات + خريطة، تقييمات ومراجعات من المستخدمين.

### الباك إند (Lovable Cloud)
جداول:
- `governorates` (27 محافظة)، `cities` (كل المدن من القائمة + مدن الجيل الرابع مع علامة `is_new_city`) — كلها تُدرَج كبيانات أولية في نفس الهجرة.
- `categories` تصنيفات شجرية (عيادات، محلات، أكشاك، مصانع، مدارس…).
- `businesses` مع `status` (pending/approved/rejected)، `owner_id`، `is_featured`، حقل بحث مُولَّد.
- `business_images`، `business_hours`، `reviews`.
- `profiles` + `user_roles` (جدول أدوار منفصل + دالة `has_role`) — الأدمن لا يُخزَّن أبدًا في جدول البروفايل.
- جداول `ads` و`events` تُترك للمرحلة الثانية.

الأمان: RLS على كل الجداول — الزوار يقرأون الأنشطة المعتمدة فقط، صاحب النشاط يقرأ ويعدّل أنشطته هو (بما فيها غير المعتمدة)، الأدمن يعتمد ويعدّل الكل. صور في التخزين مع سياسات رفع مقيدة بالمالك.

### التصميم
أبيض نظيف، أزرق `#1a73e8` كلون أساسي، نص `#202124`، خلفيات `#f1f3f4`. خط عربي حديث (Cairo/IBM Plex Sans Arabic)، اتجاه RTL بالكامل، كروت نتائج بظل خفيف وحواف ناعمة، صفحة تفاصيل بغلاف صور بارز.

### خطوات التنفيذ
1. تفعيل Lovable Cloud + هجرة الجداول والصلاحيات والسياسات، مع إدراج كل المحافظات والمدن والتصنيفات الأولية.
2. نظام التصميم RTL + الخطوط والألوان في `src/styles.css`.
3. صفحة البحث الرئيسية + مكوّن شريط البحث.
4. صفحة النتائج (كروت + فلاتر + ترقيم صفحات) عبر دوال خادم عامة.
5. صفحة تفاصيل النشاط + صفحة المدينة، مع بيانات وصفية خاصة لكل صفحة.
6. المصادقة (بريد/كلمة مرور + جوجل) ولوحة صاحب النشاط لإضافة نشاط ورفع صور.
7. لوحة الأدمن: طابور المراجعة، إدارة المحافظات/المدن/التصنيفات، تمييز الأنشطة.
8. SEO: عناوين وأوصاف لكل صفحة، بيانات JSON-LD من نوع LocalBusiness، خريطة موقع.

### ملاحظات تقنية
- TanStack Start: التحميل عبر route loaders + دوال خادم؛ القراءة العامة بمفتاح publishable وسياسات `anon` ضيقة، والكتابة عبر دوال محمية بالمصادقة.
- المسارات المحمية تحت `_authenticated/`، وصفحات الأنشطة عامة قابلة للفهرسة.
- الخريطة تُحمَّل على العميل فقط لتفادي مشاكل SSR.
